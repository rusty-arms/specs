# Behaviour specs

One spec per behaviour, written from what an observer sees while running the game in Dolphin. Start from [the behaviour template](../templates/behaviour.md). Rules: [CONTRIBUTING.md](../CONTRIBUTING.md).

The planned list comes from the research brief's open unknowns (core's `docs/research/brief.md`, sections 6 and 12). None of it is observed yet.

| Behaviour | Spec | Status | Notes |
|---|---|---|---|
| Simulation tick rate, and which logic is tied to frame rate | None yet | Not started | Unknown; measure in Dolphin |
| Per-level logic: what each level does on load, unload, every frame and when drawing | None yet | Not started | A lead from Exavolt's docs puts this at 42 pieces; verify by observation |
| Script native functions: what each one does | None yet | Not started | Rebuilt from observed behaviour and the names the scripts import |
